# A workbench for useful ideas

Audience: collaborators, research teams, and people hiring an engineer who thinks about the complete user journey.

Palette: paper #faf9f6, ink #252329, lilac #e8e1f4, purple #7053a6, mint #dfecdc, butter #f2e5a8. Use lilac as the dominant hero surface; project illustrations inherit their own material color.

Typography: Arial/Helvetica grotesk for large, tightly spaced display type and body text; Georgia only for a handwritten-note-like editorial aside. No remote font dependency.

Layout: wide inset hero with left-aligned headline and an asymmetric interactive project constellation on the right; two-column work gallery; full-width interactive demo; two-column personal introduction; generous closing contact section.

Review: A generic portfolio would lean on skill badges and invented impact numbers. This version uses actual project subjects as visual objects, a transparent illustrative workout interaction, and specific engineering questions. The workbench is the bold visual; supporting sections are quiet. No stock portrait is substituted for the user.

Content is drafted from prior conversation memory, not a fresh project audit. Exact ownership, outcomes, dates, URLs, education, résumé and portrait remain explicit placeholders. Project mockups are original illustrative representations, not screenshots of released software.
